
🚀 Day 8 — Git Fundamentals Practical Work

🎯 Objective

Practice the basic Git workflow used to manage and contribute to a project.

---

1. Check Repository Status

git status

What I practiced:
Checked the current state of my Git repository and identified modified, staged, and untracked files.

---

2. Check Remote Repository

git remote -v

What I practiced:
Checked the GitHub repository connected to my local repository.

---

3. Stage Changes

git add .

What I practiced:
Added my changes to the Git staging area.

---

4. Check Staged Changes

git status

What I practiced:
Confirmed that my files were staged and ready to commit.

---

5. Create a Commit

git commit -m "Add Git practical work"

What I practiced:
Created a commit to save my changes in the local Git repository.

---

6. View Commit History

git log --oneline

What I practiced:
Viewed the commit history of my repository.

---

7. Check File Changes

git diff

What I practiced:
Checked the differences between my current changes and the previous version.

---

8. Create a Branch

git switch -c git-practice

What I practiced:
Created a separate branch for practicing Git.

---

9. Check Branches

git branch

What I practiced:
Viewed the branches in my repository.

---

10. Switch Between Branches

git switch main

What I practiced:
Switched from the practice branch back to the main branch.

---

11. Merge a Branch

git merge git-practice

What I practiced:
Merged the changes from my practice branch into the main branch.

---

12. Push Changes to GitHub

git push origin main

What I practiced:
Uploaded my committed changes from the local repository to GitHub.

---

🔄 Git Workflow

Make changes
     ↓
git status
     ↓
git add .
     ↓
git commit
     ↓
git push
     ↓
GitHub

✅ Day 8 Completed

I practiced the basic Git workflow and learned how to check changes, stage files, create commits, work with branches, merge changes, and push my work to GitHub.
